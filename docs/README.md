# Legacy Docs Directory

This `docs/` directory is deprecated.

The canonical RustF documentation now lives in:

- Source: `book/src/`
- Published book: <https://numerum-tech.github.io/rustf/>

What remains in `docs/`:

- legacy markdown that has not yet been migrated or removed
- internal notes, plans, and historical reference material
- compatibility files such as `RUSTF_SKILL.md`

If a `docs/*.md` file disagrees with the book, treat the book as authoritative.
